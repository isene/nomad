# fresh

**[Download for Android (APK)](https://github.com/isene/nomad/releases/download/apk/fresh.apk)** · [how to install](https://isene.org/nomad/#get)

Every app you installed, newest first.

- Reads install times from PackageManager (`firstInstallTime`).
- User-installed apps only; system apps are filtered out.
- Icons load as their rows come into view.
- Tap an app to open it; long-press for app info or uninstall.
- No Rust core, no network, no background work.
